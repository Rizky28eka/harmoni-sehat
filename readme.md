# Harmoni Sehat Project

This is the monorepo for the Harmoni Sehat application, which includes both the backend API and the frontend application.

## Project Structure

-   `harmoni_sehat_backend/`: Contains the Node.js/Express.js backend API.
-   `harmoni_sehat_frontend/`: Contains the React/TypeScript frontend application.
-   `docs/`: Comprehensive documentation for both frontend and backend.

-   **[Backend API Documentation](./harmoni_sehat_backend/README.md)**
-   **[Frontend Application Documentation](./harmoni_sehat_frontend/README.md)**

## Features

This project aims to provide a comprehensive healthcare management system with features such as:

-   User Authentication and Authorization (Role-Based and Ownership-Based)
-   Patient Management
-   Doctor Management
-   Medical Record Management
-   Drug Management
-   Drug Cart and Order Management
-   Clinic and Specialization Management
-   And many more healthcare-related functionalities.
